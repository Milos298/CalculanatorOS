# Python Calculanator — módy a přístroje

Samostatné počítačové ukázky Pythonu. Spouští se například `python calculator.py`. Nejde o firmware pro Pico; Pico verze je v Dokumenty/CalculanatorOS.

- `calculator.py`: interaktivní kalkulačka.
- `matrix_mode.py`: textový Matrix režim.
- `instrument_panel.py`: simulované přístroje (teploměr, stopky, měřič náhodných hodnot).
